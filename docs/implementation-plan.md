# 《思乡曲》中秋沙画实施计划

## 项目目标

制作一部可在浏览器中播放、可部署至 Vercel、并能导出为分享视频的沉浸式中秋沙画。作品以《思乡曲》的歌词意境为叙事线索，通过月夜木楼、远山烟云、海外游子、椰林、慈母与梧桐叶等意象，呈现由惆怅走向绵长思念的情绪变化。

## 视觉与技术方向

- 使用 Vite、TypeScript 和 Canvas 2D 构建轻量前端应用。
- 采用暖琥珀色灯箱、深褐色沙粒、纸张纤维和暗角营造真实沙画质感。
- 动画由绝对时间驱动，并使用固定随机种子，保证实时播放、进度跳转和视频导出的画面一致。
- 场景以沙粒汇聚、擦除、风吹和意象变形衔接，避免普通幻灯片式淡入淡出。
- 实际画面由数千个独立沙粒组成；每粒沙在场景间沿弧线迁移，转场时加入手掌扫痕、飞散残影、持续落沙和底部积沙，而不是把静态线稿简单淡入淡出。
- 支持桌面和移动设备，并为 `prefers-reduced-motion` 提供低动态模式。

## 分镜规划

1. **序章 · 沙落成月**：沙粒在黑暗中落下，汇聚为中秋圆月与远山，片名随风散去。
2. **月照木楼**：月光照亮木楼小窗，镜头拉远，远山、云烟与近水依次展开。
3. **隔海相望**：水中月影变成游子的眼睛；游子与故乡窗边的母亲隔山隔水望月。
4. **椰风诉情**：泪滴化作海湾涟漪，椰树在风中摇曳，游子手中的旧信引出回忆。
5. **故园慈母**：故乡草木、母亲整理衣领、月下团聚与门前送别以剪影呈现。
6. **梧桐叶落**：梧桐叶化作小船与家书，漂过海面，落入游子掌心。
7. **尾声 · 天涯共月**：同一轮月照亮故乡与异乡，山海合成圆环，留下“此情此意久长”。

## 动画系统

- `SandRenderer`：负责灯箱背景、颗粒纹理、沙画路径和局部沙尘。
- 场景时间轴：每幕包含进入、停留、变形、退出和意象交接阶段。
- 镜头系统：支持缓慢推拉、横移、暗角与轻微呼吸感。
- 字幕系统：当前句清晰显示，上一句化作沙尘；移动端使用稳定的底部布局。
- 播放器：提供开始、暂停、重播、进度、静音、字幕和全屏控制。

## 视频导出

### 浏览器导出

- 使用独立 Canvas 按固定分辨率绘制，并通过 `captureStream` 与 `MediaRecorder` 生成 WebM。
- 导出界面提供横屏与竖屏比例、字幕开关和清晰度选择。
- 若浏览器具备兼容编码能力，可优先提供 MP4；否则稳定回退至 WebM。
- 导出过程显示进度、取消操作和完成后的下载入口。

### 高质量 MP4

- 提供 `npm run export:video` 自动化脚本。
- Playwright 按固定帧率调用确定性渲染入口并逐帧截图。
- FFmpeg 将序列帧编码为 H.264 MP4，并可混入已获授权的正式音轨。
- 预置 16:9 横屏和 9:16 竖屏输出；竖屏使用重排构图而非简单裁切。

## Vercel 部署

- 使用 Vite 生产构建，并通过 `vercel.json` 声明构建目录及静态资源缓存策略。
- 配置页面标题、描述和 Open Graph 分享信息。
- 视频的高质量离线编码不依赖 Vercel Serverless Functions，避免长时间计算成为线上播放的阻塞项。

## 分阶段交付

1. 完成灯箱、沙粒引擎和“圆月—木楼—山水—游子”的视觉小样。
2. 抽象场景和确定性时间轴，补齐所有叙事段落与响应式构图。
3. 加入播放器、歌词同步和浏览器视频导出。
4. 加入 Playwright + FFmpeg 的高质量 MP4 工作流。
5. 完成性能、可访问性、移动端和浏览器兼容测试后部署 Vercel。

## 验收标准

- Vercel 生产地址可直接访问，完整动画可暂停、恢复、重播和拖动。
- 歌词、画面与可选音轨由同一时间线同步。
- 网页可生成至少一种可下载的视频格式。
- 本地命令可稳定生成 1080p MP4，并支持横屏和竖屏预设。
- 正式视频不因设备实时性能发生掉帧，且相同时间点可重复生成相同画面。
- 无授权歌曲时仍可播放及导出环境声或静音版本。
